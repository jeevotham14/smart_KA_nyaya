# Experiment Summary

This document summarizes the complete ML progression for the Smart Karnataka Nyaya baseline model.

## Progression Steps
1.  Real ILDC dataset
2.  Dataset verification
3.  Leakage discovery
4.  Leakage cleaning
5.  Leakage diagnostics
6.  TF-IDF baselines
7.  Feature ablation
8.  Calibration analysis
9.  Robustness analysis
10. Input compatibility analysis
11. Final locked TEST evaluation
12. Selective prediction evaluation
13. Frozen inference integration

## Disclaimer on Synthetic Models
The original synthetic/dummy model results generated early in the project were **discarded** and must never be reported as final results.
